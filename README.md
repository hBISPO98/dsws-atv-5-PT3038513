# Formulário ​P3 📑​
Aplicação web desenvolvida em Flask que conta com um formulário interativo para inserção de nome utilizando Flask-WTF. O projeto mantém o padrão PRG (Post/Redirect/Get) para o tratamento seguro de requisições, design responsivo estilizado com Bootstrap e herança de templates via Jinja2.
